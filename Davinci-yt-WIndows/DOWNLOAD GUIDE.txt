YOUTUBE FOR RESOLVE DOWNLOAD GUIDE

Thanks for downloading, this installer copies the plugin into DaVinci Resolve's Scripts folder, but a few things need to be installed on your system first for it to actually run.



1. Before running the installer, make sure you have:

 1. DaVinci Resolve installed, with at least one project created
 2. Python 3.10 or newer
 3. ffmpeg
 4. The following Python packages: `PySide6`, `PySide6-Addons`, `yt-dlp`

IF YOU ALREADY HAVE PYTHON AND PIP SET UP, SKIP TO STEP 3.
IF YOU DONT HAVE THE PREREQUISITES INSTALLED, COPY THE COMMANDS GIVEN BELOW AS IS AND WAIT. 


REMOVE THE DOUBLE APOSTROPHE ENCLOSING THE COMMANDS BEFORE EXECUTION.
---




2. Installing Python (if you don't have it)

Copy these commands into the terminal as is and wait.

-MacOS

"brew install python"

(IF YOU DON'T HAVE HOMEBREW: INSTALL IT FIRST FROM HTTPS://BREW.SH/, THEN RUN THE COMMAND ABOVE.)

-Windows
Download the installer from python.org/downloads — during setup, make sure to check "Add python.exe to PATH" before clicking Install.

---




3. Installing the required Python packages

Open a terminal(macOS: Terminal.app) or Command Prompt(Windows), and run:

"pip3 install PySide6 PySide6-Addons yt-dlp"

---




4. Installing ffmpeg

MacOS-
"brew install ffmpeg"


Windows-
"winget install ffmpeg"

Or download manually from ffmpeg.org and add its `bin` folder to your system PATH.

to verify the download-
"ffmpeg -version"

You should see version info printed, not a "command not found" error.

---



5. Running the installer

MacOS- double-click the .pkg file. If macOS warns that its from an unidentified developer, right click the file, Open instead of double clicking.

Windows- double-click the .exe file. If Windows warns you, click More info → Run anyway.

---



6. Launching the plugin

1. Open DaVinci Resolve with a project loaded
2. Go to Workspace -> Scripts
3. Look for the plugin in the list and click it
